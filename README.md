# Molecular Edit Flows

Research codebase for **Evidence-Calibrated Molecular Edit Flows**: learning transferable continuous flows over masked molecular edits and calibrating their property effects from a few measurements for low-data, lead-preserving multi-property optimization without retraining the chemical generator.

## Repository Structure

```
1_research_file/        Research plan, mathematical & experimental designs, study notes, and result logs
2_data_storage/         Raw and processed molecular datasets
3_model_training/       Core package and experiment runner scripts
4_experimental_result/  Controlled benchmark modules and experimental outputs
5_test/                 Unit and integration test suite
```
